# Anshu Kumar — Cinematic Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge, or use VS Code Live Server.
3. Edit `index.html` to add your real GitHub/LinkedIn/LeetCode URLs if desired.

## Files
- `index.html` — portfolio content and structure
- `style.css` — cinematic responsive styling and animations
- `script.js` — scroll reveal, counters, cursor glow, mobile navigation and progress bar

## Resume basis
Content is based on the uploaded resume. No unavailable links or extra qualifications were invented.
